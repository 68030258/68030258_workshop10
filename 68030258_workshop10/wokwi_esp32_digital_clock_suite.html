Bottom-Up Modular OOP Methodology

Hardware Abstraction Layer (HAL) built layer-by-layer up to FreeRTOS multitasking system

This project uses a rigorous Bottom-Up Object-Oriented System Architecture targeting ESP-IDF v6. Drivers are constructed and unit-tested independently without depending on higher-level business logic. The architecture decouples hardware components (I2C Bus, DS1307 RTC, SSD1306 Display, Debounced Buttons) from domain logic engines (TimeManager, AlarmEngine, StopwatchEngine) via standard C++ interfaces and thread-safe FreeRTOS primitives (Queues, Mutexes, Event Groups).

FreeRTOS Multitasking Specification

Task Name Priority Stack Size Core Trigger / Period Responsibilities
vTaskClockDisplay 3 (Medium) 4096 B Core 1 Periodic (100 ms) Renders current active mode (Time, Alarm, Stopwatch) to SSD1306 buffer and flushes I2C frame.
vTaskButtonHandler 5 (High) 3072 B Core 0 ISR Queue Event Processes debounced switch presses, detects long-press events, and toggles clock operational modes.
vTaskAlarmCheck 4 (Med-High) 2048 B Core 1 Periodic (1000 ms) Compares DS1307 system RTC time against stored alarm time. Triggers LEDC piezo buzzer PWM when active.
vTaskNTPSync 1 (Low) 6144 B Core 0 Periodic (3600 s) Connects to Wi-Fi SSID 'iotexpo', queries pool.ntp.org, adjusts internal POSIX system time, and updates DS1307 RTC registers.
